# RDP Session Manager 0.7.3

Fixes RDP sessions closing immediately when desktop startup receives a disconnected D-Bus session address. Session creation and session-type changes now use the system-managed user bus when available, with dbus-run-session providing a bus whose lifetime follows the application otherwise.

The fix covers desktop, RemoteApp and profile-based session entry points. Existing users receive the updated entry point when their session configuration is regenerated; installing this release alone does not rewrite existing user home files.

Validation: session tests, full unit suite, shell syntax checks and installer bootstrap tests. A fresh RDP login remains necessary to verify the complete desktop on each target machine.
